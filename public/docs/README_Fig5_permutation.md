## Fig. 5 population-activity and permutation analysis

This analysis quantifies neuronal activity rate, pairwise population coordination and population dimensionality across behavioural states and time periods surrounding A/C administration.

### Input data

The analysis uses the processed input table [`Fig5_permutation_input_N10.csv`](./Fig5_permutation_input_N10.csv). Each row contains one mouse-level estimate for a specified metric, behavioural state and time window. Ten mice were included in the analysis.

The behavioural states were classified as:

- **Immobile**
- **Mobile**

For each state, measurements were obtained in three time windows:

- **Before A/C:** −45 to 0 min
- **After A/C:** 0 to 45 min
- **1 h after A/C:** 45 to 120 min

The reported analysis includes four metrics:

1. **Firing rate**
2. **Mean pairwise Spearman correlation**
3. **Normalized participation ratio (PR norm)**
4. **Normalized number of principal components explaining 50% of the variance (PC50 norm)**

Mean pairwise Spearman correlation was used as the principal measure of population coordination. It represents the signed mean of pairwise Spearman correlation coefficients across the recorded neuronal population. A reduction in this measure indicates reduced mean pairwise coordination, but does not by itself distinguish changes in the positive and negative components of the full correlation distribution.

PR norm was calculated from the eigenvalue spectrum of the covariance matrix and represents the effective dimensionality of population activity normalized by the number of recorded neurons. PC50 norm represents the number of principal components required to explain 50% of population variance, also normalized by neuronal number. An increase in PR norm or PC50 norm indicates that population activity is distributed across a larger number of dimensions.

### Statistical analysis

All analyses were performed using [`Fig5_Permutation_test.py`](./Fig5_Permutation_test.py).

For each mouse and comparison, a paired difference was calculated as:

$$
d_i = Y_{i,\mathrm{comparison}} - Y_{i,\mathrm{Before}}.
$$

Paired comparisons were evaluated using a two-sided exact sign-flip permutation test. The test statistic was the mean within-mouse difference:

$$
T_{\mathrm{obs}} = \frac{1}{n}\sum_{i=1}^{n} d_i.
$$

Under the null hypothesis, the sign of each within-mouse difference was considered exchangeable. The null distribution was therefore generated by enumerating all possible assignments of positive and negative signs to the observed paired differences.

For $n=10$, all

$$
2^{10} = 1{,}024
$$

sign assignments were evaluated.

The exact two-sided P value was calculated as:

$$
P =
\frac{
\#\left\{
\left|T_{\mathrm{perm}}\right|
\ge
\left|T_{\mathrm{obs}}\right|
\right\}
}{
2^n
}.
$$

The following comparisons were performed separately for Immobile and Mobile periods:

1. After A/C versus Before A/C
2. 1 h after A/C versus Before A/C

These comparisons followed a prespecified fixed-sequence procedure, with the After-versus-Before comparison tested first and the 1-h-after-versus-Before comparison tested second. The second comparison was interpreted as confirmatory only when the first comparison was significant. Accordingly, no additional multiplicity adjustment was applied within each fixed sequence. Both nominal exact P values are reported for transparency.

Firing rate and mean pairwise Spearman correlation are displayed in the main figure. PR norm and PC50 norm provide supporting analyses of population dimensionality.

### Outputs

Running the script generates:

- a CSV table containing the statistical results;
- an Excel workbook containing summary statistics and individual mouse values;
- plots showing individual mouse trajectories and mean ± s.e.m. for Immobile and Mobile conditions;
- exact permutation P values for After-versus-Before and 1-h-after-versus-Before comparisons.

The script can be run from the directory containing the script and input CSV using:

```bash
python Fig5_Permutation_test.py
```

The analysis requires Python 3, NumPy, pandas, Matplotlib and openpyxl.
